# 온결 — 태어난 날에 담긴, 나의 결

기존 게임 홈페이지를 사주 원국을 살펴보는 정적 웹사이트로 개편한 정적 웹사이트입니다.
참고 이미지의 밝은 배경·따뜻한 노란 버튼·입력 흐름을 참고하여 독립적인 이름과 화면으로 구성했습니다.

## 실행

빌드나 API 키가 필요하지 않습니다. `index.html`, `styles.css`, `app.js`, `insights.js`, `report.js`, `engine.js`, `icon.svg`, `vendor/`를 함께 배포하세요. GitHub Pages 저장소 루트에서 서비스할 수 있습니다.

```sh
python3 -m http.server 8765
# http://localhost:8765
node tests/engine.test.cjs
node tests/forecast.test.cjs
node tests/report.test.cjs
```

## 구현 범위

- 소개 → 정보 입력 → 입력값/보정 시각 확인 → 결과
- 이름(선택), 양력 생일, 출생 시간/모름, 국내 대표 도시
- 시주→일주→월주→년주 원국, 천간·지지 십성, 표면 오행 분포
- 지장간(본기부터), 일간에 따른 12운성, 일간별 일반 상징 해설
- 계산 근거, 경계 시각 안내, 수정/다른 사주 보기, 인쇄, FAQ
- 모바일 대응, 키보드 포커스, 모달, 입력 검증, 사용자 문자열 HTML 이스케이프

신살·용신·신강/신약·음력·해외 출생·실시간 AI 상담은 구현하지 않았습니다. 사용자가 선택한 범위는 성격, 연애 상담·연애운, 대운 타임라인, 올해·내년 운세입니다. 해설은 미리 작성한 규칙 기반 설명이며 AI 생성 상담이 아닙니다. 전통 성별 기준은 선택 사항이며 대운의 순·역행에만 사용합니다.

## 계산 기준

1. 1970~2026년 한국 출생의 양력만 입력합니다. 날짜·시간·도시를 검증합니다.
2. `Intl.DateTimeFormat`의 `Asia/Seoul` 시간대 자료로 해당 출생 순간과 서머타임을 판별합니다. 1987/1988년 등의 중복/존재하지 않는 시각은 거부합니다.
3. 년·월주는 출생 순간을 달력 라이브러리의 UTC+8로 변환하여 절기에 비교합니다. KST 시계를 그대로 중국 시간으로 대입하지 않습니다.
4. 보정 선택 시 표준시에서 `(경도−135)×4분 + 균시차`를 적용합니다. 균시차는 제공받은 참고 문서의 날짜별 근사식을 사용합니다. 이 보정은 일·시주에만 사용하며 절기 판정의 출생 순간은 바꾸지 않습니다.
5. 일주는 보정된 날짜의 00:00에 바뀝니다. 자시는 보정 시각 23:00~01:00이며 시주의 천간도 해당 날짜 일간으로 산출합니다. 23:00에 일주를 바꾸는 학파의 규칙과는 다릅니다.
6. 시간 미상은 시주를 만들지 않습니다. 정오의 년·월·일주를 참고값으로 계산하며, 절기일에는 별도 경고합니다. 보정으로 날짜까지 달라질 가능성을 포함해 시간 미상은 확정값이 아님을 표시합니다.
7. 오행은 표면 천간·지지의 단순 빈도입니다. 지장간·계절 가중치 및 전문적인 강약 판정이 아닙니다. 소수 반올림으로 합이 100.0%와 다를 수 있습니다.
8. 지장간은 `lunar-javascript`의 본기 우선 관례와 일치시킵니다. 십성과 12운성의 모든 조합을 업스트림 표/공식에 대조했습니다.

## 제공받은 사주 프롬프트 반영

`AI_Saju_Gemini_v9.md`는 참고자료로만 사용했습니다. 전체 문서를 공개 저장소에 복사하지 않았습니다.
반영한 사항: 입력 확인, 동일 입력의 일관성, 시각 보정 정보, 시간 미상, 원국 순서, 십성/지장간/12운성.

문서의 진태양시에 다시 30분 이동한 자시 경계(23:30)를 적용하는 방식은 채택하지 않았습니다. 본 구현의 경계는 보정된 태양시 기준 23:00입니다. 따라서 문서의 예시 1990-05-15 서울 07:30은 약 07:01로 보정되어 본 구현에서는 진시이며, 문서의 묘시와 다릅니다. 문서에는 조자시의 추가 날짜 보정에 관한 상충 설명도 있어 그대로 구현하지 않았습니다. 절기는 검증되지 않은 제공 CSV를 별도로 내장하지 않고 달력 라이브러리를 사용합니다.

## 데이터와 개인정보

입력 정보는 서버 요청·URL·localStorage·쿠키에 저장하지 않으며 현재 페이지 메모리에서만 처리합니다. 결과를 인쇄하는 경우 사용자가 파일로 저장할 수 있습니다. Google Fonts를 불러오므로 글꼴 요청은 발생하지만 입력값은 전송하지 않습니다. 네트워크가 없으면 시스템 글꼴을 사용합니다.

## 외부 소스와 검증

- `vendor/lunar.js`: https://github.com/6tail/lunar-javascript 의 소스를 2026-10-19 내려받아 저장했습니다. MIT 라이선스는 `vendor/LICENSE-lunar.txt`에 포함했습니다. 실행 중 외부 달력 서비스에 요청하지 않습니다.
- 14개 계산 테스트: 업스트림 사례, 60갑자 기준일, 절기 경계, 자정 이동, 자시 경계, 시간 미상, 서머타임과 중복/누락 시각, 잘못된 입력, 십성 100조합 및 12운성 120조합.
- 브라우저에서 입력 → 확인 → 결과 및 시간 미상 흐름을 확인했습니다.
- 소스는 GitHub main 브랜치에서 관리합니다. 공개 웹사이트 배포는 GitHub Pages 설정에 따릅니다. 기존 게임은 Git 이력에서 복구할 수 있습니다.


## 성격·연애·대운·올해/내년 확장

- 결과 화면의 네 개 탭: 성격 / 연애 상담·연애운 / 대운 타임라인 / 올해·내년 운세.
- 성격: 일간의 상징, 강점·돌아볼 점, 표면 오행 비율. 전체 원국 성격 감정이나 심리검사가 아닙니다.
- 연애: 솔로·알아가는 중·연애 중을 선택하고 연락·표현·갈등 질문을 고릅니다. 일간·해당 연도 십성에 대한 일반 해설과 상태/질문별 미리 작성한 대화 가이드를 조합합니다. AI API를 호출하지 않습니다. 상대의 마음·연애 성공률·성사/재회/이별 시기를 예측하지 않습니다.
- 대운: 선택한 전통 성별 기준 + 실제 출생 순간으로 lunar-javascript `getYun(gender, 2)`를 사용합니다. 절기 간격을 분 단위로 기산합니다. 진태양시로 바꾼 표시 시각을 기산에 중복 적용하지 않습니다. 첫 대운 이후 9개 구간을 표시합니다.
- 대운 시작 시각은 UTC+8 계산 결과를 실제 순간으로 바꾼 뒤 KST로 표시합니다. 각 구간은 `[시작 시각, 다음 시작 시각)`으로 현재 여부를 판단합니다. 일자 표시에는 분·초를 생략하므로 전환일 당일에는 실제 시각에 따라 달라질 수 있습니다. 타임라인의 나이는 시작일 만 나이입니다.
- 출생 시간 미상 시 대운은 정오 기산의 참고값이며 경고를 표시합니다. 전통 성별 기준 미선택 시 대운만 비활성화하고 입력으로 이동할 수 있습니다.
- 올해/내년은 브라우저의 현재 순간을 Asia/Seoul 연도로 변환해 자동 갱신합니다. 연도 간지는 60갑자로 계산합니다. 한 해의 간지는 입춘~다음 입춘 기준이라는 설명을 표시합니다. 1월에는 ‘현재의 세운’이 아닌 그 달력 연도의 입춘 이후 흐름을 설명합니다.
- 연도 해설은 일간과 연도 천간의 십성에 따른 일반적 상징입니다. 지지 본기 십성도 근거로 표시하되 원국·대운의 합충형해를 종합하거나 좋고 나쁨을 점수화하지 않습니다.
- 11개 추가 테스트: 한국 연도 경계, 순·역행, 업스트림 간지 일치, 대운 구간 연속성·경계 포함 규칙, 진태양시와 기산 분리, 시간 미상·선택 생략·표시 범위 전후, 결정론. 기존 계산 14개 포함 총 25개 테스트 통과.


## 서술형 풀이 개편 (v3)

사용자 피드백에 따라 질문/관계상태 선택, 풀이 근거 버튼, 반복되는 한 줄 카드 해설을 제거했습니다. 해설을 원국 차트보다 먼저 표시합니다.

`report.js`에서 일간 상징, 월지 계절, 오행 단순분포, 일간 대비 표면 천간·지지 본기의 십성 빈도, 운의 일지 육합·육충·반복을 조합하여 문단 단위의 성격·연애·대운·세운 풀이를 생성합니다. 숨은 천간 전체 가중치·신강신약·용신·삼합·형파해의 종합 판정은 하지 않습니다. 계절은 월지에 따른 상징 분류이며 수치 강약 모델이 아닙니다.

- 성격: 태어난 계절과 내면 / 힘을 쓰는 방식 / 오행 / 일상의 방향.
- 연애: 애정 표현 / 편안한 관계와 지치는 장면 / 올해 관계 변화 / 내년 흐름.
- 대운: 원국의 성향과 운의 십성 주제를 비교하고, 일지와 운 지지의 직접 육합·육충·같은 지지 반복을 문단으로 해설.
- 세운: 각 해의 이야기, 원국 일지와의 관계, 일상에서의 방향, 해당 입춘~다음 입춘 구간과 겹치는 대운의 배경. 대운 중첩은 실제 절기 순간으로 비교하며 임의의 2월 4일 0시를 쓰지 않습니다.
- AI API는 호출하지 않습니다. 생성 모델처럼 어떤 입력에나 자유로운 새 해석을 만드는 서비스는 아닙니다. 규칙의 조합에 포함되지 않는 새로운 상호작용은 해설하지 않습니다.
- 기존 25개에 더해 8개 해설 테스트: 결정론, 시간미상, 합·충 대칭, 선택 대운의 차이, 같은 일간/다른 월주의 서술 차이, 실제 입춘 경계, 모든 일간의 결과 완전성. 총 33개 통과.
